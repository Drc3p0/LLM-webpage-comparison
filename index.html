LLM Cat Site Comparison

Evaluating how different large language models build, design, and structure a codebase from the exact same design prompt.

THE PROMPT 
Build a single-file cat portfolio website for GitHub Pages.

OUTPUT REQUIREMENTS:
- One file only: index.html
- All CSS and JS must be inline (no external files)
- No external dependencies, frameworks, or CDN links
- Must work as a static GitHub Page with no build step

DESIGN REQUIREMENTS:
- Clean, modern layout with a soft color palette (creams, warm grays, dusty rose, or slate)
- Fully responsive (mobile and desktop)
- Smooth scroll navigation
- Use CSS Grid or Flexbox for layout

CONTENT SECTIONS (in this order):
1. Hero — full-width banner with a cat name/title and a short one-liner bio
2. Photo gallery — CSS Grid layout using local images at paths: photos/01.jpg through photos/05.jpg
3. Links section — three styled link buttons:
   - Instagram: https://instagram.com/PLACEHOLDER
   - Personal website: https://example.com
   - A "Contact" mailto link
4. Footer — simple, minimal

CONSTRAINTS:
- No placeholder lorem ipsum text — write real, witty cat-themed copy
- Photo gallery must degrade gracefully if images are missing (show a styled placeholder box)
- All interactive elements must be keyboard accessible
- Keep total HTML under 200 lines

DO NOT include explanations, markdown, or code fences in your response. Output only the raw HTML.
